## 在新 Windows 电脑上安装

1. 下载需要的技能 ZIP，并保存同目录的《给Codex的安装提示词.txt》。GitHub 文件页可使用 Download raw 下载。
2. 在新电脑的 Codex 中提供 ZIP 或其本地完整路径，将对应安装提示词全文发送给 Codex。
3. Codex 按提示词检查 Python、安装依赖、准备运行环境并执行本机验收。安装需要网络和相应的本地权限。
4. 尺寸调整技能展示新账号初始规则和预览，用户确认后启用。实际图片任务均先确认参数和预览，再批量生成。

提示词应与同目录的 ZIP 配套使用；仅有提示词无法取得 ZIP 内的私有脚本。技能安装到当前 Windows 账号，运行环境和个人偏好由目标电脑建立。仓库未包含原图、旧账号配置、反馈历史、模型权重或 Python 依赖环境。

## 功能

- **尺寸调整**：先确定上衣／外套、裤子、眼镜／雪镜、帽子、鞋靴、全身或自定义主体，再逐图规划；默认等比铺满、无新增白边。支持每批反馈、长期修改审批、账号隔离及版本回退。详见 ZIP 内《使用说明.md》。
- **白底透明图**：生成 800×800 白底 JPG 和透明 PNG，默认主体长边占 80%；每款汇总白底、透明两份含各颜色图层的 PSD。默认 CPU 串行和 PS 优先模式。详见 ZIP 内《使用说明.md》。
- 白底透明图目录附带《降低占用率提示词.docx》作为补充参考；当前迁移包已启用该模式，正常安装无需再次修改。

这两份是面向 Codex 的 Windows 迁移包。存入 MewCode 仓库用于保存和下载，不代表已接入 MewCode 自身的技能加载目录或运行工具。

## 文件校验与验证范围

[SHA256SUMS.txt](SHA256SUMS.txt) 记录六份原始交付文件的 SHA256。可用 PowerShell `Get-FileHash -Algorithm SHA256 -LiteralPath "文件完整路径"` 核对。

发布前已检查两包 ZIP 完整性、包内 MANIFEST、外部安装提示词一致性，并排除旧备份及本地运行配置。包内验收记录来自已有 Windows 环境；新电脑仍需执行自己的安装和功能验收。
